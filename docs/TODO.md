# 待辦清單

唯一的待辦清單。做完一項就在同一個 commit 裡移到「已完成」並附 commit 編號。
延後的設計題（陣營、二樓、EMP、兵源等）見 [`design.md` §16](design.md#16-待定問題)，這裡不重複。

優先度：**P0** 先做（穩住目前版本）、**P1** 實測後決定、**P2** 有需要再做。

## P1：遊戲性（實測後決定）

- [ ] 主動請求友軍支援某一格（目前只有交戰在友軍家 2 格內才自動支援）
- [ ] 友軍規則式無線電訊息（「Charlie：在路上，約 30 秒」）
- [ ] 自主等級「自由」太主動：交戰中固守 40 秒就自己推進 → 改成先提議
- [ ] 平衡再檢查：連續地圖進攻 C3，3 守軍約 50～70%、4 守軍約 25%（`scripts/ab_batch.py`）
- [ ] 戰後復盤（AAR）：用結構化事件產生摘要（誰被誰打倒、誰救了誰、用了哪些支援）
- [ ] 命令生命週期顯示（送出 → 理解 → 執行中 → 完成／中斷）
- [ ] 固定遭遇補場景：急救／拖人、警戒射擊、看不到的射手（`scripts/encounter.py` 目前沒有）
