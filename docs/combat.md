# Area Commander — 戰術層與戰鬥公式（草案 v0.1）

> 狀態：設計草案，尚未實作。所有數值都是起點，會在戰術引擎原型與情境測試中調整。
> 與 `docs/design.md` 的關係：design.md 描述作戰層（5×5 區域地圖、任務、補給、敵方指揮），本文件描述每一格內的戰術層與戰鬥結算。

---

## 0. 總覽：兩層地圖

```
作戰層（5×5）                     戰術層（每格 10×10，永久存在）
D3 通訊中繼塔                     D3 內部：地形、高度、掩體、每個個體的位置
  小隊＝一個點                      隊員、敵兵各佔一格
  任務／補給／情報／敵方指揮          視線、掩體、高度、壓制、損傷
```

- 戰術地圖**永久存在**：每一格都有自己的 10×10 地圖，單位在格內有精確位置，平時就在。
  - 這讓「已經布好陣」有意義：守軍會長時間待在選好的位置（窗口、屋頂、掩體後），並累積構工。
- 作戰層負責：行軍、任務、補給、情報、敵方指揮決策。
- 戰術層負責：格內移動、發現、射擊、壓制、損傷、士氣。
- **進入方向**：小隊從 C3 進入 D3，會從 D3 的南邊緣進場。作戰層的路線選擇＝戰術層的接觸方向（繞路本身就是側翼）。
- **跨格射擊**：v1 不做（見 §17）。

### 0.1 地圖來源
- 主要地點（任務地點、敵方據點，例如 D3 中繼塔、E2 工廠）**手畫**。
- 其他格子依地形類型用**模板生成**（開闊路口、建築廢墟、枯樹林…），以固定 seed（場景 id＋格子代號）生成，同一格每次都長一樣。

## 1. 地格（tile）屬性

| 屬性 | 值 | 作用 |
|---|---|---|
| 地形 | 空地／瓦礫／牆／窗口／植被／門／樓梯 | 移動成本、是否擋視線 |
| 高度 | 0 地面、1 二樓、2 三樓、3 屋頂 | 視線、命中、視野 |
| 掩體 | 無／半／全，**有方向**（N/E/S/W，可多向） | 只對來自掩體正面扇形的射擊有效 |
| 隱蔽 | 0～2（植被、陰影） | 只影響被發現機率，不擋子彈 |
| 構工 | 0～3 | 布陣時間累積，掩體升級 |

移動成本：空地 1、瓦礫 2、樓梯 2、植被 1、牆不可通行、窗口可射擊不可通行、門 1。

## 2. 個體屬性

| 屬性 | 說明 |
|---|---|
| 位置／高度／朝向 | 朝向決定視野扇形與側翼判定 |
| 姿勢 | 站／蹲／臥：越低越難被打中，但移動越慢、視野越短 |
| 武器 | 見 §9 |
| 熟練度 | 每類武器 0～200，見 §10 |
| 部位損傷 | 軀幹／腿／手臂／頭部（感測器），見 §7 |
| 彈藥 | 每人一個彈藥百分比（0～100%），可分給相鄰隊友 |
| 壓制值 | 0～100，見 §6 |
| 狀態 | 正常、移動中、被壓制、釘死、倒地、離線（陣亡） |

敵兵在戰術層同樣是個體；作戰層仍可用 strength 總數表示，進入戰術層時展開為個體（實作細節見 §18）。

## 3. 時間與行動

- 1 tick = 10 秒（不細分子回合）。雙方**同時行動**。
- 每人每 tick **2 行動點（AP）**：

| 行動 | AP |
|---|---|
| 移動 1 格 | 1（瓦礫／樓梯 2；腿部損傷 ×2） |
| 瞄準射擊 | 2 |
| 連發（打 2 次） | 1 |
| 壓制射擊 | 2 |
| 換姿勢 | 1 |
| 警戒（overwatch） | 2：敵人進入視野時自動開火 |
| 撿武器／互換武器 | 1 |
| 分彈藥給相鄰隊友 | 1（雙方平分） |
| 急救（穩定倒地者） | 2 |
| 拖行倒地者 | 移動成本 ×2 |

- **結算順序**：移動 → 警戒觸發 → 射擊 → 壓制／損傷 → 士氣。
  衝過開闊地會吃到警戒火力。

## 4. 視線與發現

### 4.1 視線
- Bresenham 線段；牆、較高的地形會擋。
- 高處可越過較矮的障礙（例如二樓可越過一般瓦礫看到後方）。
- 窗口：可從窗口向外看與射擊，窗口後方的人只有從窗口正面扇形可見。

### 4.2 發現機率（每 tick 判定）
```
基礎 80%（距離 ≤3）→ 每多 1 格 −8%
× 目標姿勢（站 1.0／蹲 0.7／臥 0.45）
× 目標隱蔽（每級 −25%）
× 目標正在移動 ×1.5；本 tick 剛開火 → 必定暴露
× 觀察者高度（每高一層 +10%）
× 觀察者頭部損傷 ×0.5
```

### 4.3 伏擊
- 未被發現的一方首次射擊：命中 ×1.5，且目標本 tick 不觸發警戒。

### 4.4 認知分離
- 雙方都只知道自己看到的。最後已知位置會保留並標示時間，可能過時。

## 5. 射擊命中公式

```
命中率 = 射擊技能（由武器熟練度決定，見 §10）
       × 距離係數    （≤2 格 1.1、3–5 格 1.0、6–8 格 0.75、>8 格 0.5；依武器射程調整，見 §9）
       × 掩體係數    （目標掩體面向射手：半 0.65、全 0.35；側翼／背面 1.0；每級構工再 ×0.92）
       × 高度係數    （射手每高一層 ×1.15；高 2 層以上時目標半掩體失效）
       × 目標姿勢    （站 1.0、蹲 0.85、臥 0.7；臥姿對高處射手無效）
       × 射手狀態    （本 tick 移動過 0.7、被壓制 0.6、釘死盲射 0.15、手臂損傷 0.6）
       × 射擊模式    （瞄準 1.0、連發 0.7 ×2 次、壓制 0.3）
上限 0.9，下限 0.03
```

- **側翼判定**：以目標掩體方向為中心的 90° 扇形；射手不在扇形內＝側翼，掩體完全無效。
- 命中後依 §7 擲部位。

## 6. 壓制

讓「先壓制再推進」成為有效戰術，同時讓構工良好的據點難以壓制。

### 6.1 累積
- 子彈落在目標 1 格內（未命中）：+10；壓制射擊：+20；命中：+25。
- 乘以武器壓制係數（§9）與熟練度係數（§10）。
- **再乘以掩體修正**（掩體面向射手時；側翼不打折）：

| 狀態 | 壓制累積倍率 |
|---|---|
| 無掩體 | ×1.0 |
| 半掩體 | ×0.7 |
| 全掩體 | ×0.45 |
| 每級構工 | 再 −10%（最低 ×0.25） |
| 被高處俯射 | 半掩體視為無掩體 |

### 6.2 門檻（固定）
- **≥ 50：被壓制**：命中 ×0.6，不能移動到開闊地。
- **≥ 80：釘死**：
  - 無掩體：只能趴下或往掩體爬。
  - 有掩體：可以**盲射**（壓制射擊，命中 ×0.15），維持一點壓制但打不準。

### 6.3 消退（每 tick）

| 狀態 | 消退 |
|---|---|
| 無掩體 | −20 |
| 半掩體 | −25 |
| 全掩體 | −30 |
| 每級構工 | 再 −5 |
| 隊長在旁（2 格內） | 再 −10 |

效果：輕機槍持續壓制，打空地上的人約 2～3 tick 就釘死；打 3 級構工、全掩體的守軍幾乎壓不住，必須包抄（讓掩體失效）或搶高點俯射。

## 7. 部位損傷（生化人）

| 部位 | 機率 | 損壞效果 |
|---|---|---|
| 軀幹 | 45% | 累積 2 次 → 倒地 |
| 腿 | 25% | 移動成本 ×2，不能奔跑 |
| 手臂 | 20% | 命中 ×0.6；兩臂皆損 → 無法射擊 |
| 頭部／感測器 | 10% | 視野減半、發現機率 ×0.5；20% 直接倒地 |

### 7.1 倒地、救援、回收
- **倒地 ≠ 陣亡**。倒地者不能行動。
- 倒地後 **N tick（暫定 12）** 內未處理，或倒地時再被擊中 → **離線（陣亡）**。
- 隊友可**急救**（2 AP）穩定倒地者：計時暫停。
- 隊友可**拖行**倒地者（移動成本 ×2）帶回後方據點修復。
- 被留在原地、該格被敵方控制時，敵方可**回收**倒地者 → 接到被俘／駭入／重編程（見 design.md 4.3）。
- 敵方倒地者同理，我方也可回收（未來可接「俘獲重編」）。

### 7.2 與作戰層的對應
- 作戰層的「傷員」＝有部位損傷的隊員；整補在後方據點修復部位損傷。
- 作戰層的「陣亡」＝離線。

## 8. 士氣（小隊層級）

### 8.1 變化（每 tick）
```
− 隊友倒地／陣亡     −15
− 隊長倒地            −25
− 被側翼攻擊          −10
− 全隊平均壓制 > 50   −5／tick
− 兵力比 < 1:2        −5／tick
+ 擊倒敵人            +8
+ 在掩體內且未受威脅   +2／tick
```

### 8.2 連線加成
- **與指揮官連線中：所有士氣門檻判定都用「士氣 + 10」**（有效士氣）。
- 士氣本身範圍 0～100，無底線。

### 8.3 門檻（用有效士氣判斷）

| 有效士氣 | 行為 |
|---|---|
| ≥ 45 | 正常 |
| 20～44 | 動搖：不接受「推進」類意圖，自動找掩體 |
| 6～19 | 潰退：交替撤退往後方邊緣，可能違令 |
| ≤ 5 | 每 tick **2%** 機率投降（→ 被俘） |

- 連線中有效士氣最低為 10 → **永遠不會投降**，生化人死戰到底，指揮官不會被機率性投降坑到。
- **失聯時**失去加成 → 士氣跌破 5 才可能投降。敵方電子戰（干擾通訊）因此成為真正的威脅。
- 隊長的信念／傾向可微調門檻（例如老灰較難潰退、回聲較易動搖）；不改投降規則。

## 9. 武器

| 武器 | 有效射程 | 基礎命中 | 壓制 | 彈藥消耗／發 | 特性 |
|---|---|---|---|---|---|
| 突擊步槍 | 6 | 1.0 | +10 | 4% | 預設、均衡 |
| 輕機槍 | 7 | 0.85 | +20（壓制射擊 +30） | 3% | 移動後命中 ×0.5；壓制主力 |
| 精確射手步槍 | 10 | 1.15 | +5 | 8% | 8 格內不衰減；不可連發 |
| 霰彈槍／近戰裝備 | 2 | 1.3（≤2 格） | +10 | 6% | 3 格外命中急降；突擊加成 |

- 超出有效射程後套用 §5 的距離係數衰減。
- 彈藥 0% 時只能撿彈、向隊友要彈或近戰。

## 10. 武器熟練度（0～200）

每個隊員對每類武器（步槍／輕機槍／精確射手／霰彈槍近戰）各有熟練度。

### 10.1 區間

| 區間 | 意義 | 成長 | 衰減 |
|---|---|---|---|
| 0～100 | 學習期：生手 → 熟練（100＝很會用） | 正常 | 不衰減 |
| 100～200 | 精通期：高度專精 | 很慢 | 會衰減，最低回到 100 |

### 10.2 成長（每次交戰結算）
- 射擊 +0.5、命中 +1、擊倒 +3。
- 0～100：× (1 − 熟練度 / 150)。
- 100～200：再額外 ×0.3。

### 10.3 衰減
- 僅作用於 100 以上部分：該武器每 **30 tick** 未使用 −1，最低 100。

### 10.4 效果

| 項目 | 0 | 100（熟練） | 200（精通） |
|---|---|---|---|
| 射擊技能（§5） | 0.45 | 0.60 | 0.70 |
| 命中額外係數 | ×0.8 | ×1.0 | ×1.15 |
| 壓制累積 | ×0.8 | ×1.0 | ×1.15 |
| 彈藥消耗 | ×1.2 | ×1.0 | ×0.9 |
| 近戰判定（霰彈槍／近戰） | ×0.8 | ×1.0 | ×1.2 |
| 輕機槍移動後命中 | ×0.4 | ×0.55 | ×0.7 |
| 精確射手開始衰減距離 | 6 格 | 8 格 | 10 格 |

（0～100 線性內插，100～200 線性內插；0～100 曲線影響大＝「從不會到會」，100～200 影響小＝「從會到頂尖」。）

### 10.5 初始值
- 新兵：步槍 40、其他 10。
- 老兵：主武器 100～130、副武器 50～70。
- 角色卡可直接指定；LLM 生成小隊時依背景給。

### 10.6 150 以上小技巧（待定）
例如：機槍手可移動中壓制、射手首槍不暴露位置。先記錄，之後再決定是否實作。

## 11. 編制、換裝

### 11.1 班型模板（依比例，不寫死人數）

| 班型 | 規則 |
|---|---|
| 均衡班 | 機槍 ≈ 1/4、射手 ≈ 1/4（3 人以上各至少 1），其餘步槍 |
| 步槍班 | 全步槍 |
| 偵察班 | 射手 ≈ 1/2，其餘步槍 |
| 火力班 | 機槍 ≈ 1/2，其餘步槍 |
| 突擊班 | 霰彈槍 ≈ 1/2，其餘步槍 |
| 狙擊班 | 全射手 |
| 破門班 | 全霰彈槍 |

- 四捨五入；多出或不足的名額用步槍補。
- 換裝時武器優先分給該武器熟練度最高的隊員；新兵補入時依模板補缺口。
- 極端編制（全射手、全霰彈槍）允許：各有明顯弱點，地形決定吃不吃香（開闊的 D3 利於射手、室內的 E2 利於破門）。

### 11.2 換裝規則
- **後方據點**：可自由換成任何班型，或逐人指定武器；耗時同整補。
- **前線**：只能撿倒地隊友／敵人的武器、與隊友互換，或由補給空投附帶指定武器。
- **指揮官可口頭指定**（例如「R-12 改拿機槍」）：在前線需有可用武器；在據點下次換裝生效。
- 換成不熟的武器 → 熟練度懲罰（§10）。長期維持同一編制有價值。

### 11.3 班組（採用 A）
- **不設班組加成**。班型名稱由目前武器配置**自動判斷，只做顯示**（例如「目前配置：偵察班」）。
- 理由：能力應該來自「人」（熟練度、經歷、信念），不是來自標籤；避免指揮官為了迎合班組加成而配裝。
- 其他方案列於 §17 可能改動方向。

## 12. 近戰／突擊

- 衝到相鄰格即判定（突擊意圖或霰彈槍近距）。
- 雙方各擲：`熟練度近戰係數 × 狀態 × 武器近戰係數（霰彈槍／近戰 1.3、步槍 1.0、機槍 0.8、射手 0.7）`。
- 修正：被壓制 ×0.5、釘死 ×0.2、腿部損傷 ×0.7；從側翼或未被發現時突擊 ×1.5。
- 輸方倒地（§7.1）；平手雙方各擲一次部位損傷。

---

## 13. 構工

- 同一位置停留每 **30 tick** 升 1 級，最多 3 級；一移動就歸零。
- 敵方據點守軍初始為滿級。
- 構工影響：命中（掩體係數）、壓制累積與消退（§6）、隱蔽（每級 +0.5，最多 +1）。

## 14. 戰術意圖與站位

### 14.1 隊長（LLM）只選意圖
LLM 不逐格操作。引擎給隊長看**局勢摘要**（文字），隊長選一個意圖＋參數：

| 意圖 | 引擎執行 |
|---|---|
| 推進到 [區域] | 掩體跳躍，一半人移動一半人掩護 |
| 固守 | 原地選最佳掩體，設警戒 |
| 壓制 [目標] | 集火目標，壓制快速累積 |
| 包抄 左／右 | 一半人壓制，另一半繞到能打側翼的位置 |
| 搶高點 | 移動到最近且安全的高處 |
| 交替撤退 [方向] | 兩組輪流掩護後撤 |
| 伏擊 | 隱蔽臥倒，等敵人進近距離才開火 |
| 突擊 | 全員衝最近的敵方位置，近戰判定 |
| 救援倒地者 | 掩護一人去拖回倒地隊友 |

局勢摘要範例：「敵兵兩名在北側二樓窗口；我方三人在瓦礫半掩體後；左翼是開闊停車場；R-15 腿部受損。」

### 14.2 站位評分（規則）
```
分數 = 對已知敵人的掩體值 × 3
     + 高度 × 1.5
     − 暴露於已知敵人視線的數量 × 2
     + 接近意圖目標
     − 與隊友重疊
```
每個隊員依評分選格子、依武器與意圖選射擊對象。

### 14.3 敵方
用同一套規則；意圖由敵方 AI 規則選擇（不呼叫 LLM）。

## 15. 指揮官看到什麼

- 戰術地圖只畫**小隊看得到的範圍**＋敵人最後已知位置（標時間）。
- 隊長回報會提到地形（由局勢摘要提供）。
- 無人機掃描／空拍：留待網頁版（§18）。

## 16. 平衡目標（情境測試）

| 情境 | 期望結果 |
|---|---|
| 4 對 3，雙方皆在開闊地 | 約 3～5 tick 分出勝負 |

## 17. 可能改動方向

### 17.1 班組模型
- **B：班組＝訓練**：班組有行為加成（偵察班發現率＋、突擊班近戰＋），與武器無關；「偵察班全拿機槍」合法。
- **C：班組＝訓練＋照編制協同加成**：B 之外，裝備符合模板時有小加成；名實不符不懲罰；班組可由長期使用自然轉型。
- **從人身上長出小隊特色**：不設班組；系統或隊長依成員熟練度與戰歷產生描述（例如「擅長近距巷戰，R-15 是最好的射手」），隊長反思時可能長出「我們是突擊隊」之類信念，影響意圖選擇，但不給數值加成。
- 目前感覺「班組（制度標籤）」與「小隊（一群人）」有概念衝突，B／C 可能讓指揮官為了加成而配裝。暫用 A。

### 17.2 指揮部要求換裝
任務可能建議或指定編制；是否有獎勵取決於班組模型，待定。
