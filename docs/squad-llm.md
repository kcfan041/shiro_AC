# 小隊長與 LLM

小隊長（以及接手帶隊的人）由 LLM 扮演。本文件說明 LLM 能做什麼、不能做什麼，以及服從、成長、自主的規則。
相關：[總覽](overview.md)、[戰術層](tactical.md)（性格怎麼影響戰術 AI）、[網頁介面](interface.md)。

時間以網頁版為準：作戰 tick 5 秒、戰術層執行步 0.5 秒。以「10 秒」校準的作戰層規則在網頁版乘上 `ticks_per_10s`（2），換成秒數後和 Discord 版（10 秒 tick）大致相同。

## 1. 分工原則：引擎是裁判，LLM 是演員

```
引擎：計算局勢 → 列出可選行動 → 擲服從結果
  ↓
LLM（隊長）：讀角色卡、信念、記憶、命令、局勢 → 輸出 JSON（行動、目標、回報）
  ↓
引擎：驗證行動合法 → 結算 → 寫入經歷與事件
```

- LLM 不決定戰鬥結果、不決定服從與否、不決定誰受傷。這樣結果才一致，也不怕指揮官用話術操弄。
- 只在關鍵時刻呼叫 LLM：收到命令、交戰事件、反思、需要開口的新角色。其餘由規則驅動。
- LLM 一律在背景執行，不在 tick 鎖內等待。等待期間戰場照常推進。

## 2. 下令

### 2.1 打字下令

1. 指揮官的訊息先分類：`order`（命令）、`question`（詢問）、`chatter`（閒聊）。只有 order 會改變行動。
2. order 帶 `confidence`：
   - high：明確。
   - low：隊長用自己的理解解讀，可能要求澄清（行動不變），也可能照自己的理解執行（猜錯也照做，結果由引擎結算）。回執顯示「不太確定」。
   - none：在小隊能力與可選行動裡找不到對應，行動不變，並記進經歷（`mapped=null`），之後可能觸發反思。
3. 地點用地名或格子代號都可以（「通訊中繼塔」「中繼塔」「D3」）；隊長回覆的 `target`、`via` 由引擎換成格子（[operations.md §1](operations.md#1-地圖enginescenariosurbanjson)）。
   隊長簡報有「地點」一行，列出全部地點的「地名（代號）」（`scenario.places_text`，可限定範圍，之後大地圖只列附近）；沒有這一行時隊長只認得相鄰格和據點，會回「地圖上沒有標出某某」。
4. 小隊能力見 `engine/units.py`（步兵：突擊步槍、短距無線電、光學／熱感測、急救模組；沒有重武器、載具、支援火力）。
5. 送出後畫面馬上顯示「回覆中…」。

### 2.2 快捷按鈕、地圖點選

快捷按鈕和作戰圖點選**當場擲服從判定、當場生效**，不等 LLM；口頭回覆之後在背景補上。被拒絕時行動不變。
標定點（集結／包抄／集火／陣地）仍走打字下令的流程，會等 LLM。

**構工**（`fortify`，只有連續地圖才在可選行動裡，因為挖坑改地形要經地圖變更層）：口頭下令（例如「就地構築陣地」）由 LLM 對應到 `fortify`；
要在別處構工，先移動過去再下令，或在戰術圖用「⛏陣地」標定點。引擎替每人分坑位、決定胸牆方向，見 [operations.md §2.1](operations.md#21-構工連續地圖fortify)。
構工是保守的行動，不算危險命令。

### 2.3 服從判定（`engine/obedience.py`）

服從由引擎擲骰，數值不給玩家，也不給 LLM 看。

| 項目 | 值 |
|---|---|
| 基準（依「執行方式」傾向） | 字面 92、意圖 78、自己的方式 55 |
| 有效士氣 < 45 | −10；< 20 再 −15 |
| 能作戰的人 ≤ 一半 | −5 |
| 危險命令 | −15（字面傾向只 −5） |
| 範圍 | 5～97 |

- 擲出 ≤ 分數 → 照辦；剩下的前 2/3 → 變通；其餘 → 拒絕。
- 打字下令時同時擲「一般」和「危險」兩個結果，依 LLM 判斷這道命令是否危險（`risky`）採用其一。
- 快捷按鈕的危險命令：突擊、破門，或彈藥 < 30% 時推進／壓制推進／包抄。
- **要求確認**：隊長有「驗證要求」傾向、命令危險、且 LLM 選擇要求確認 → 進入 `pending_confirm`，指揮官重申後才執行（下一道命令會帶「已確認」說明）。
- 回執：理解、行動、照辦／變通／拒絕／要求確認（另有 info、unclear、failed、keep）。不顯示機率。

## 3. 自主等級

每支小隊有三種等級，預設「自由」：

| 等級 | 例行事件（沒有威脅） | 有威脅時 |
|---|---|---|
| 待命 | 只能 keep／hold／hide，其他只能**提議** | 只能做保命動作；交戰外不會自己撤退 |
| 自衛 | 同上 | 只能做保命動作 |
| 自由 | 同上 | 不限 |

- 提議：隊長想做但無權做的行動，會在小隊卡片上顯示，指揮官按「同意」才執行。
- 自主行動：隊長自己決定的行動會標示原因，指揮官可以按「取消」。
- 自由等級、交戰中、固守不是指揮官下的令、還有已知敵人 → 固守滿 40 秒就依應變準則的「推進卡住」自己行動（標示為自主）。
- 推進卡住會自動改包抄（待命等級除外）。
- **自主構工**（連續地圖）：不在交戰、固守（有沒有下令都算）連續 60 秒（`AUTO_DIG_S`）、不在後方據點、有人站在能挖的地方 →
  自由等級直接構工（標示為自主，可取消）；待命、自衛改成提議「在這裡挖散兵坑構築陣地」，同一格只提一次。
- 切換等級：按鈕，或指揮官口頭說（例如「待命」）時由 LLM 在回覆裡設定。

## 4. 回報

- 交戰事件觸發隊長回報，事件分三種：
  - **緊急**（馬上反應）：接敵、傷亡、倒地、潰退、請求新指示、彈藥打光、撤出、擊倒敵人、脫離接觸、補給、歸隊。
  - **非緊急重大事件**：至少隔 10 秒，期間排隊（最多保留 6 件）。
  - **次要事件**（負傷、壓制等）：同一小隊至少隔 30 秒。
- 構工時所有人都挖到最深（或沒地方挖）→ 一次「陣地構築完成」事件（非緊急重大事件）。
- 隊長的作戰層狀況有「地形（本格與相鄰格）」一行：有標籤的格子列出高地、散兵坑、土堤（[operations.md §10.1](operations.md#101-地形摘要engineterrain_summarypy)）。
- 隊長的戰術簡報有「地形」一行（有高低差時才有）：幾人在深坑／淺坑、幾人正在挖、敵我高低差（1.5 m 以上才說）、
  已知敵人有幾人在散兵坑或低窪處（只看情報裡的最後位置）。
- 接敵事件寫接觸當下的實際狀況（`Engagement.contact_detail`）：看到幾名敵軍、最近的在哪個方向多遠、敵人有沒有向小隊開火、我方幾人可作戰、傷亡與被壓制的人數。不一律說成「近距離接觸」。
- 有威脅的事件發生時，若小隊正在執行指揮官的命令，提示詞會寫出命令內容，提醒隊長依實際威脅（距離、開火、傷亡、壓制、兵力對比）衡量，單純發現敵人或遠距離接觸不構成放棄命令的理由。要不要撤退仍由隊長自己決定（自主等級照舊）。
- 隊長可以選擇不回報（`report=null`）：不回報，情報表就不更新。「會不會主動回報」本身就是情報。
- 事件回覆還在路上時指揮官下了新命令 → 這次回覆只說話，不改行動。
- 友軍（Charlie、Delta）的規則式無線電會進小隊的對話紀錄，隊長回話時看得到（標成「友軍無線電」）。
- 少量閒聊：指揮官下過令之後，固守時約每 30～60 tick 可能隨口說一句，也可能不說。

### 4.1 失聯

- 通訊正常時，自己小隊的狀態即時顯示（數據鏈）；失聯時畫面停在最後一次資料（「📵 失聯｜T 的資料」），快捷按鈕停用。
- 失聯後閒置 6 tick 會觸發一次自主事件，隊長依最後命令與自己的個性行動。
- 恢復通訊時，隊長補報失聯期間的經過，並觸發反思。

## 5. 信任與態度：經歷 → 反思 → 信念 → 傾向

信任不做成單一數值，態度也不固定。三層：

```
① 經歷（引擎記錄，不可竄改）
   事實：t / kind / text / mapped / outcome / 服從結果 / risky
   解讀：interp（隊長當下寫的一句想法，主觀、不分類）
        ↓ 反思（事件後觸發，由 LLM 扮演隊長本人）
② 信念（隊長自己寫的句子，最多 6 條，標記「出廠」或「經驗」）
        ↓
③ 傾向（每次反思重選）
   請示傾向／驗證要求／主動性／執行方式（字面、意圖、自己的方式）
```

- **不用固定評價標籤**（例如「荒謬命令」）：同一件事，不同隊長解讀不同。事實層只記引擎能驗證的東西。
- 反思的輸入只有經歷。**玩家不能用嘴改變信念，只能用行動。**
- 入侵懷疑不寫死：世界觀告訴隊長「敵方能偽造通訊」，懷疑由反思自然產生；產生後「驗證要求」傾向會打開。
- 傾向的作用：執行方式 → 服從基準；驗證要求 → 危險命令先要求確認；請示傾向、主動性 → 寫進提示詞，影響隊長會不會請示、會不會主動回報。
- 出廠信念寫在角色卡 `initial_beliefs`；老兵的既有看法寫在 `experience_beliefs`。信念文字沒改過才保持「出廠」標記。
- 反思也寫一句長期記憶（`long_memory`，上限 400 字）與應變準則（§6）。
- 經歷最多保留 60 筆。

### 5.1 反思觸發

任務結束、隊員陣亡、交戰結束（敵軍全滅或脫離接觸）、撤出交戰、換人帶隊、恢復通訊、收到無法對應或可疑的命令。

- 排進佇列，**脫離交戰後**才執行；同一小隊至少隔 6 tick（網頁版 30 秒）；每 tick 最多一支小隊反思。
- LLM 額度不足時延後（見 §8）。
- 提示詞要求信念慢慢改變：一次通常只動 1～2 條，出廠信念要反覆重大經歷才會推翻。

## 6. 應變準則（SOP，`engine/sop.py`）

帶隊者「卡住時通常怎麼改戰術」，六種情境：

| 情境 | 意思 |
|---|---|
| stalled | 推進卡住（已知敵人在建築內時改判為 enemy_in_building） |
| downed | 隊員倒地 |
| ammo_low | 彈藥見底 |
| pinned | 被壓制 |
| enemy_in_building | 敵人在建築內 |
| outnumbered | 兵力劣勢 |

- 反思時由 LLM 順便寫；沒寫過就依性格推（積極 − 謹慎越高越傾向突擊、包抄、破門；謹慎或重情偏撤退）。
- **只當備援**：交戰中 LLM 叫不到（被限流）或呼叫失敗時才用。
- 目前行動是指揮官下的令時，準則只能改成保命動作（固守／隱蔽／撤退）。
- 自由等級的「固守 40 秒自己推進」也用 stalled 的準則（§3）。
- 敵方依單位類型用固定準則；批次模擬用準則當簡易隊長。

## 7. 隊員個體：人格、白紙兵、換人帶隊

### 7.1 人格

- 每名隊員有四項性格：積極、謹慎、沉著、重情（−1～+1），和人格值（0～1，性格影響行為的程度）。
- 戰術上的影響與交戰後的演化見 [戰術層](tactical.md#15-性格)。
- 人格值：新兵 0.1，每場有實際接觸的交戰 +0.05，上限 0.8。

### 7.2 白紙兵（C 模式）

- 新兵只有數字（天生傾向小值＋低人格值），沒有個性文字。
- 需要開口時（目前是接手帶隊時）才請 LLM 依數字與經歷寫出個性、說話風格、台詞、信念。
- 人格值跨過 0.4、0.7 時重寫一次。
- 開局小隊照角色卡：隊長有完整人格，其他人是白紙兵。

### 7.3 換人帶隊

- 發言人倒下 → 接手順序：曾帶隊者 > 人格值最高 > 沉著最高。
- 每個人有自己的信念、傾向、應變準則，換人時一起換；系統提示與反思改用接手者自己的人格。記憶與經歷整隊共用。
- 原隊長回據點整補完成後恢復指揮。

## 8. LLM 後端與額度（`lib/llm.py`）

- OpenAI 相容 API（目前用 9router），`.env` 設定 `LLM_BASE_URL`／`LLM_API_KEY`／`LLM_MODEL`，回傳 JSON。逾時 90 秒，重試 1 次。
- 每分鐘上限 `llm_max_per_minute`（預設 60），滑動視窗，依優先序保留額度：

| 優先 | 用途 | 規則 |
|---|---|---|
| 1 | 接令、交戰回報 | 一律可叫 |
| 2 | 副官、角色生成 | 一律可叫 |
| 3 | 反思 | 剩餘額度 < 10% 時延後 |
| 4 | 閒聊 | 剩餘額度 < 25% 時略過 |

## 9. 副官

給新手的輔助 LLM：

- **只讀指揮官情報表**（加上任務與最近 8 行紀錄；交戰結束的戰後摘要也寫進這份紀錄），不會洩漏真相，也可能判斷錯。
- 輸出 2～4 句現況，加上 2～4 個建議行動按鈕。按下等於以指揮官身分下令，仍經服從判定。
- 指揮官狀態有變時自動更新，最多每 30 秒一次；也可以按「更新」。LLM 失敗時退回「回報現況／原地固守」。
- 副官看得到其他指揮官小隊的位置與人數，但不能指揮。

## 10. 角色卡

角色卡放在 `setting/squads/<id>.json`（範例在 `setting example/squads/`）：

- 隊長：名字、個性、口頭禪、背景、`initial_beliefs`、`experience_beliefs`、`tendencies`、`long_memory`。
- `start`（起始位置）、`max_size`（滿編人數）；成員可以寫成 `{"name", "trait"}`。
- 增援小隊、救回殘部自成的小隊由 LLM 生成，只為隊長寫人格與呼號。
