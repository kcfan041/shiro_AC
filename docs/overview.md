# Area Commander（shiro_AC）總覽

戰爭指揮遊戲：玩家扮演宏大戰役中的一名**地區指揮官**，不在前線，只能透過通訊掌握戰況，對由 LLM 扮演的機器人小隊下令。
目前開發重點是**網頁版**（`server.py`，`terrain_v1` 分支）；Discord 版（`bot.py`）凍結維護。

## 1. 設計主軸

- **你不在戰場**：所有資訊都來自部隊回報、偵察與推測，可能過時、可能錯誤。
- **部隊是有意識的個體**：每個小隊長會思考、記憶、成長、違令（LLM 扮演）。隊員也是持久個體，有名字、傷勢、熟練度、性格。
- **戰場持續存在**：指揮官下線、部隊失聯，戰場照常運作。失聯不等於死亡。
- **戰役沒有終點**：你只是一個區域的指揮官，戰線永遠在推移。
- **引擎是裁判，LLM 是演員**：戰鬥結果、服從判定全由引擎計算；LLM 只負責理解命令、選擇行動、說話、反思。
- **真相與認知分離**：引擎只模擬真相，每位指揮官只看得到自己的情報表。有限資訊由架構保證。
- **戰術結果自然發生**：規則一致、資訊不完全、角色依資訊決策；不寫克制倍率。

## 2. 世界觀

- 時代：現代以後（近未來～科幻）。
- 前線作戰單位是**生化人／機器人**：陣亡、駭入、拆解、重編程都合理；「記憶＝資料」「服從＝協議」，讓 LLM 扮演、偏離、記憶累積都有依據。
- 敵方能偽造通訊（寫在世界觀說明裡，隊長可能因此起疑）。
- 陣營：待定。

## 3. 結構

```
最高司令部（系統）      戰略目標、增援與補給分配
   │
戰線（多個區域）        區域結果影響相鄰區域          ← 尚未實作
   │
地區指揮官（玩家）      只管自己的區域；目前一個區域最多 4 位指揮官
   │
小隊（可下令）          最小可控單位，隊長由 LLM 扮演
   │
個體（不可操控）        名字、傷勢、熟練度、性格、經歷
```

兩層模擬：

| 層 | 範圍 | 內容 | 文件 |
|---|---|---|---|
| 作戰層 | 5×5 大格 | 行軍、任務、補給、兵源、友軍、敵方指揮 | [operations.md](operations.md) |
| 戰術層 | 每格 25×25（50 m），連續地圖時拼成 125×125 | 個體位置、視線、彈道、壓制、傷勢、士氣、戰術 AI | [tactical.md](tactical.md) |

## 4. 玩家怎麼玩（網頁版）

1. 註冊 → 報到處「就任指揮官」→ 領一支起始小隊（4 人）。
2. 打字下令，或用快捷按鈕、作戰圖點選；隊長回覆理解與照辦／變通／拒絕／要求確認。
3. 設定自主等級（待命／自衛／自由），決定隊長能自己做多少事。
4. 看常駐戰術圖、隊員面板、即時戰況；看不到的敵人只畫最後位置。
5. 呼叫指揮部支援（精準空投、煙幕、無人機）、請求補給、請求友軍後送傷員。
6. 跑主線與支線任務；傷亡靠整補、補兵、增援補回，預備兵池用完就沒了。
7. 隊長在重大事件後反思，形成自己的信念與傾向，例如開始對可疑命令要求確認。

細節：[小隊長與 LLM](squad-llm.md)、[網頁介面](interface.md)。

## 5. 目前做到哪

**已完成**

- MVP：單支小隊、LLM 隊長、副官、多指揮官、命令理解、經歷紀錄、尋路、回報節奏。
- 信任與態度：經歷 → 反思 → 信念 → 傾向（取代舊的 protocol／deviation／trust 數值）。
- 任務與補給：主線循環、支線、整補、空投、補兵、增援、閒聊、LLM 生成小隊。
- 地圖與敵方 AI：5×5 場景檔、巡邏／守軍／機動、騷擾、據點補兵、敵軍上限依指揮官人數。
- 戰術層：永久 25×25 戰術地圖、持久個體、交戰改由戰術層結算（C1～C2）、隊長選戰術意圖（C3）、敵方戰術指揮（C4）、自我暴露推算、投擲物／架槍／閃光彈／破門、隊員性格與人格值、白紙兵、預備兵池、遊蕩生化人、營救殘部（綠方）、換人帶隊、應變準則、多指揮官同格。
- 網頁版：純網頁介面、數據鏈與失聯、下令回執、自主等級、隊員面板、戰術畫面與迷霧、回放、指揮部支援、標定點；作戰 tick 5 秒、戰術層執行步 0.5 秒（每個人的動作各有時間）。
- 連續地圖：活動區域、真實行軍、跨格接敵與射擊；常駐戰術圖、作戰圖彈窗、迷你圖。
- 戰術圖（PixiJS）：流暢播放、程式化地形與機兵、特效與空間化音效、我方視野、小隊意圖與命令狀態、注意力提示、回放時間軸與戰後摘要。
- Phase 0／E：固定遭遇與基線、結構化事件、行動理由、伺服器端迷霧過濾。
- AI 修正：下令移動遇敵不取消、架槍避開隊友、一人救一人、交戰外拖著傷員行軍。
- 友方電腦小隊 Charlie、Delta；請求後送。
- 效能：LLM 改背景、路徑搜尋範圍縮小、慢拍 log。
